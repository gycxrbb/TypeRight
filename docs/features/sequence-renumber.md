# 功能规格：序列重排（序列一键重排）

## 概述

插入或删除条目后，`1.` `①` `（1）` `1）` `一、` 这类**手动敲的序号**后面全部要顺延改——本文档场景高频且机械。序列重排一键扫描全文，把**断序**的序列（缺号/重号/乱序）重排为 `1..n`。

- 入口：功能区「序列重排」/ 右键「序列一键重排」（`btnRenumber` / `ctxRenumber`）
- 单次点击 = 一个撤销记录（`TypeRight 序列重排`），Ctrl+Z 整体还原
- 纯文本操作，Word/WPS 全支持，无公式/表格依赖

## 支持的标记类型（9 种）

| 类型 | 形态 | 取值范围 |
|---|---|---|
| `1.` / `1．` | 阿拉伯+点（半/全角点同流，各保留原点） | 1-999 |
| `1、` | 阿拉伯+顿号 | 1-999 |
| `（1）` | 全角括号 | 1-999 |
| `(1)` | 半角括号 | 1-999 |
| `1）` | 尾全角括号 | 1-999 |
| `1)` | 尾半角括号 | 1-999 |
| `①…㊿` | 带圈（①-⑳ U+2460，㉑-㉟ U+3251，㊱-㊿ U+32B1） | 1-50 |
| `一、` | 中文数字+顿号 | 一~九十九 |
| `（一）` | 全角括号中文数字 | 一~九十九 |

超出范围（带圈 >50、中文 >99）：**整流跳过**并提示，不做半截重排。

## 核心规则（保守优先）

1. **只动断序的序列**：首值 1 且严格连续的序列原样不碰。
2. **断 1 开新流**：条目值为 1 且非流首 → 新序列（试卷分大题重新起号是常态）。因此 `1,2,3 | 1,2` 两大题互不干扰。
3. **单条目流不动**：孤立的 `5.` 可能是行内序号的续文，无法推断意图，绝不改。
4. **重排以 1 为基数**：断序流一律重排为 `1..n`（删头场景 `2,3,4 → 1,2,3`）。
5. **选区感知**：有选区时只处理与选区有序号交集的序列，且**整流处理**（含流内选区外条目，避免半流重排错号）。
6. **同流各保留原装饰**：`1.` 与 `1．` 同流重排，每条保留自己原来的点。

## 误伤防护

- `1.5 米`（小数）：点后跟数字 → 非序号
- `2026.11.10`（日期）、`2026 年`（无装饰年份）：拒绝
- Word 自动编号（numPr）段落：文字里不含序号 → 天然不匹配
- 中文数字仅认 `一~九 + 十`（两/百/零等非标准序号写法拒绝）

## 已知边界（设计取舍）

- **尾部孤立 1**：`1,2,1` 中第二个 `1` 按新流处理（单条目不动）——插入时误敲 `1.` 想接续的场景不会自动接号（与"大题重新起号"无法区分，保守不动）。插入条目请按习惯敲相邻号（重号/缺号都能修）。
- **行内 ①②③④ 选项标签**（题干中部）不是段首 → 天然不受影响；但"段落以 ② 开头而 ① 在题干行内"的续文块会被视作缺头流重排（罕见布局，Ctrl+Z 可还原）。
- 页眉页脚/脚注是独立 Story，不在扫描范围。

## 实现

`src/TypeRight.Core/Sequences/SequenceRenumberer.cs`

- **纯逻辑层**（无 Word 依赖，xUnit 直测）：`TryParseMarker`（段首标记解析）、`PlanCore`（分类型 → 断 1 切流 → 断序判定 → 变更计划）、`CnToInt/IntToCn`（一~九十九）、`CircledOf/CircledValue`（1-50）
- **Word 层**：`Plan(doc, scope)`（`WordCompat.ParagraphsOf` 枚举 + 段首解析，选区交集序号集）→ `Apply`（逐条 `doc.Range(start, end).Text = 新标记`，`Paragraph.Range` 每次现取自适应长度变化）

控制器 `RenumberSequences()`：计划 → 无变更 Toast"序号全部连续 ✓" → 有变更包 UndoRecord 应用 → Toast 摘要 + Ctrl+Z 提示。
