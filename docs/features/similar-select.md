# 功能规格：同类选择（格式签名匹配）

## 概述

光标点进一个段落 → 全文所有"格式相同"的段落一起选中（黄色高亮）→ 浮条批量改格式。

## 签名模型

5 锚点 × 4 维度，取段落可见区间的首字符、25%、50%、75%、尾字符：

| 维度 | 首尾锚 | 中段3锚 | 备注 |
|---|---|---|---|
| 中文字体名 | ✅ | ❌ | Font.Name* 对部分区间有读取抖动 |
| 西文字体名 | ✅ | ❌ | 同上 |
| 字号 | ✅ | ✅ | |
| 加粗 | ✅ | ✅ | |
| 颜色 | ✅ | ✅ | |

**不参与比对**：对齐方式（黄金取证依据）、斜体（仅展示）、下划线/删除线/着重号（仅应用端）。

**未知值语义**：Word COM 读数抖动时产生"未知"值（如 Bold=9999999），未知 ≠ 任何值（宁漏勿错）。

## 引导句感知

混合段落（行首标题句 + 正文同处一段）拆为两个独立匹配单元：

- **引导句单元**：段首到首个"非首锚格式"字符（顺序扫描，不用二分——岛状格式不满足单调性）
- **正文单元**：引导边界到段尾

用户光标位置决定匹配哪个单元（SampleOffset < leadBoundary → 引导句）。

## 分区隔离

正文样本只匹配正文段，表格样本只匹配表格内段落（`TableRanges` 位置判定）。防止 ★导读类装饰段被卷入。

## 公式区感知

`SimilarSelector.MathZoneRanges(doc)` 一次构建文档级 OMML 区间列表。所有签名锚点跳过区内字符——公式化后的文档匹配不退化。

性能注意：Word 用索引器枚举 OMaths（快路径），WPS 用底层 IEnumVARIANT 兜底（NetOffice 枚举器在两边的表现不同）。

## 宽松模式

浮条上可勾选"忽略字号/忽略颜色/忽略加粗"（可组合），勾选后实时重算（RecomputeMatches）。

默认严格模式（`Settings.StrictByDefault = true`）。

## 高亮机制

- 黄色 HighlightColorIndex 写入命中区间（**排除段落/单元格标记**——跨结束标记设置会扩散到整段）
- 包在一个 UndoRecord（"TypeRight 匹配标记"）内，Ctrl+Z 一次还原
- 会话关闭（Esc / 点击非命中段 / 文档关闭）时自动清除全部高亮
