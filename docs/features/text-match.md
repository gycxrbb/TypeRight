# 功能规格：文本同类（字义匹配）

> v0.3.0 新增，出卷场景驱动：「正确」加着重号从逐个选中变为一键批量。

## 概述

选中文字（或光标点入一个词）→ 全文所有该文本的出现处高亮 → 浮条批量改格式（如着重号）。与格式签名匹配**正交**：不看格式只看字符。

## 入口

- 功能区「TypeRight」→「文本同类」大按钮
- 右键菜单 →「文本同类」

## 匹配语义

| 规则 | 说明 |
|---|---|
| 精确文本匹配 | 逐段 Text 读取，C# IndexOf 全部命中（非重叠） |
| 否定前缀排除 | 出现处前一个字符 ∈ {不, 非, 未} → 跳过（"不正确"里的"正确"不标）。浮条上可实时开关 |
| 公式区跳过 | OMML 区间内不匹配 |
| 大小写敏感 | 西文按 Ordinal 比较 |

## 采样规则

- 有选区：直接用选区文本（2~32 字符）
- 无选区：光标处向两侧扩展连续"词字符"（`char.IsLetterOrDigit`，排除标点/空格），截取最长 32 字符

## 浮条差异

文本模式下浮条第 3 行（匹配条件行）切换为：
- `「正确」× N`（强调色显示，N = 当前命中数）
- 「排除否定前缀」复选框（切换后实时重算命中集）

格式模式的"严格/忽略字号/忽略颜色/忽略加粗"开关在文本模式下隐藏（语义不适用）。

## 着重号

浮条新增「着」两态按钮（B I U S 旁）：
- 勾上 = `Font.EmphasisMark = wdEmphasisMarkUnderSolidCircle`（字下实心圆点）
- 取消 = `Font.EmphasisMark = wdEmphasisMarkNone`

走 `BatchFormatter` 双路径写入（幂等，值没变不写）。

## 验证

构造出卷场景：9 处"正确"（含 3 处否定前缀不/未/非）→ 匹配 6 排 3 全对，零误标。
